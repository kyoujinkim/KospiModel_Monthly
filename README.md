# KospiModel_Monthly

코스피의 월간 방향·수익률 예측을 연구하기 위한 시계열 회귀·앙상블 실험 저장소입니다. Ridge, LightGBM, Random Forest와 skforecast 기반 다변량 예측, 구간·방향성 평가 스크립트를 포함합니다.


## 연구 결과

2023년 월간 코스피 보고서는 **2013-01-04 -- 2023-01-20**, 주 단위로 갱신한 월간 수익률 예측을 평가했습니다. 여기서 전체 주간 기준일의 방향 예측률과 특정 월별 투자일을 선택한 전략의 예측률은 서로 다릅니다.

| 평가 구분 | 보고된 결과 |
|---|---|
| 전체 주간 갱신 월간 예측 | 방향 예측률 59% |
| 수익률 절대오차 평균 / 중위값 | 3.4%p / 2.6%p |
| 이상치 5% 제외 평균 / 중위값 | 2.8%p / 2.0%p |
| 월별 마지막 두 번째 금요일 방향성 전략 | 예측률 65.6% |
| 동일 전략 CAGR / KOSPI CAGR | 12.7% / 2.2% |
| 동일 전략 최대낙폭 크기 / KOSPI | 35.1% / 33.3% |

따라서 65.6%를 전체 주간 표본의 월간 예측 정확도로 일반화하지 않습니다. CAGR 차이는 표시값 기준 **10.5%p**입니다. 본문의 “10.8%p 개선”과 표 3의 산술 차이가 일치하지 않아, 여기서는 표의 원 수치를 병기했습니다.

예측 구간의 명목 신뢰수준 90%에 대한 실제 포함률은 **80%**로 보고됐습니다. 구간은 예측오차 표준편차와 1.645 계수로 산출되며, 명목 신뢰수준이 실제 포함률을 보장하지 않습니다. 표 5의 향후 1개월 수익률 범위 평균 절대오차는 모형 **2.48**, 역사적 변동성 **2.58**, EWMA **2.55**, 내재변동성 **2.66**으로 모형이 낮았습니다. 반면 변동성 자체 오차는 모형 **1.03**, 내재변동성 **0.99**로 모든 지표에서 우월하지는 않았습니다(표 5의 수치 표기 기준).

같은 PDF가 `NH_Monthly_Kospi_Model`에도 있으며, 현재 저장소의 확장 실험 전체가 보고서와 같은 구현인 것은 아닙니다. 위 수치는 첨부 연구의 과거 평가이며, 현재 코드·환경에서 거래비용까지 반영해 독립 재현한 결과가 아닙니다.

출처: [230314_월간 코스피_예측모델.pdf](https://github.com/kyoujinkim/KospiModel_Monthly/blob/master/230314_%EC%9B%94%EA%B0%84%20%EC%BD%94%EC%8A%A4%ED%94%BC_%EC%98%88%EC%B8%A1%EB%AA%A8%EB%8D%B8.pdf) — PDF 9, 10, 11, 13쪽 — 전체 예측 9쪽, 구간 포함률 10쪽, 방향성 전략 표 3, 범위 비교 표 5.

## 연구 구조

```text
코스피 지수·수익률 워크북 + 기준일별 설명변수 스냅샷
  → 주간 정렬·시차 특징
  → 다기간 회귀 예측
  → 수익률 누적·앙상블 결과
  → 구간·방향성 평가
```

`ts_Boosting_backtest_new.py`는 4개 예측 구간의 수익률을 누적하는 구조를 사용합니다. 따라서 파일명에 Monthly가 있다고 해서 모든 스크립트가 달력상 한 달을 동일하게 정의하는 것은 아닙니다. 예측 간격과 누적 방식은 사용한 스크립트를 기준으로 확인해야 합니다.

| 파일·경로 | 역할 |
|---|---|
| `ts_Boosting_backtest.py` | 시계열 백테스트 실험 |
| `ts_Boosting_backtest_new.py` | Ridge·LightGBM·Random Forest 예측 조합 실험 |
| `ts_Boosting_backtest_new_Testing.py` | 추가 예측·탐색 실험 |
| `clustering_interval_result.py` | 구간 결과의 군집 분석 |
| `directional_test.py` | 방향성 관련 평가 |
| `custom_lib/skforecast_kjCustom/` | 사용자 수정 skforecast 코드 |
| `data/reinforce_result.xlsx` | 지수·수익률·설명변수 입력 |
| `model/` | 모델 관련 자산 |

## 현재 상태

과거 연구 환경에 의존하는 실험 코드입니다. 다음 항목을 정리하기 전에는 복제 직후 실행되는 패키지로 사용할 수 없습니다.

- `requirements.txt`에 로컬 빌드 경로를 참조하는 `certifi @ file:///...` 항목이 있습니다.
- 원본 skforecast 0.6 계열과 사용자 수정 라이브러리의 import가 혼재합니다.
- 외부 로컬 디렉터리의 설명변수 pickle 파일을 절대경로로 읽습니다.
- `ts_Boosting_backtest_new.py`는 `from model import parameter_setting`을 사용하지만 해당 정의를 현재 확인한 저장소 파일에서 찾지 못했습니다.
- 같은 스크립트의 LightGBM·Random Forest 경로는 `lags`를 참조하지만 현재 파일에서 해당 변수의 정의가 확인되지 않습니다.
- `model/forecaster.py`는 GitHub에서 일반 소스로 표시되지 않았습니다. 형식·생성 과정·신뢰성을 확인해야 합니다.

## 환경 복원

`requirements.txt`에는 pandas 1.5.1, NumPy 1.23.4, scikit-learn 1.1.3, LightGBM 3.3.3, skforecast 0.6.0 등 과거 환경이 기록돼 있습니다. 최신 패키지로 일괄 교체하면 API·직렬화 호환성이 달라질 수 있습니다.

1. 기존 연구 환경을 별도로 보존합니다.
2. 로컬 경로 의존 항목을 정상적인 패키지 명세로 교체합니다.
3. 실제 사용하는 패키지와 사용자 수정 라이브러리의 버전을 확정합니다.
4. `parameter_setting`, `lags`, 데이터 경로 문제를 해결합니다.
5. 검증한 환경에서 의존성 파일을 다시 생성합니다.

정리된 의존성 파일을 준비한 후 설치합니다. 아래 파일명은 정리 후의 `requirements.txt`를 뜻하며 현재 파일에 대한 설치 성공을 보장하지 않습니다.

```bash
python -m venv .venv
# 가상환경 활성화 후
python -m pip install -r requirements.txt
```

## 입력 데이터

워크북의 시트 사용은 스크립트별로 다릅니다. `ts_Boosting_backtest.py`는 `History`, `Kdrtn`, `Kidx`를 읽으며, `ts_Boosting_backtest_new.py`는 `Kdrtn`, `Kidx` 및 외부 설명변수 파일을 사용합니다. `Kidx`의 `IDX` 열 등 코드가 참조하는 이름과 날짜 인덱스를 맞춰야 합니다.

기준일별 설명변수 스냅샷에는 날짜 규칙과 종속변수 연결이 필요합니다. 시점별로 이용 가능했던 데이터만 포함하도록 구성해야 합니다. 신뢰할 수 없는 pickle/joblib 파일은 불러오지 마세요. 공개 예제는 모델 바이너리 대신 합성 CSV/Parquet와 학습 코드로 구성할 수 있습니다.

## 실행 형태

누락 정의·라이브러리·입력·경로를 복원한 뒤 저장소 루트에서 실행합니다.

```bash
python ts_Boosting_backtest.py
python ts_Boosting_backtest_new.py
```

두 스크립트는 별도 실험입니다. 한 명령의 결과가 다른 명령의 입력을 자동으로 준비한다는 의미는 아닙니다. `custom_lib`를 사용하는 스크립트에는 해당 패키지의 import 경로도 준비해야 합니다.

## 결과와 평가

`interval_result.csv`, `result.csv` 등 스크립트별 결과 파일을 생성하며 저장소의 `result_ensemble.csv`, `test_results.csv`는 연구 산출물입니다. 현재 코드가 기존 결과를 모두 동일하게 재생성하는지는 별도 확인해야 합니다.

평가에는 시간순 분할, 관측 가능 시점, 스케일링 적합 시점, 예측 구간 중첩과 데이터 수정 여부를 함께 고려해야 합니다. 방향 적중률뿐 아니라 예측 오차·비용 차감 성과·국면별 안정성을 비교하세요. 누적수익률의 단위와 퍼센트 변환도 스크립트별로 확인해야 합니다.
